**v0.4.3 更新内容**

- 压缩包解压后得到 DSH-Desktop解压包-0.4.3.exe

- 第一次运行时时间可能久一点，请耐心等待

## 特点：

1. **免安装、免部署**：exe 仅自解压，解压即可用；删除文件夹即卸载

2. **不占 C 盘**：程序与数据都在解压目录内。运行时的临时文件、用户目录、各类缓存（Node 编译缓存、npm/pnpm 下载缓存等）全部重定向到程序目录下的 `data\` 内

3. **关闭即释放**：退出时结束整个服务进程树并清空缓存，不残留后台进程、不占内存

4. **完全独立、可多开**：每个解压目录是独立实例，数据/端口/缓存互不影响。理论上可以用一个客户端修复另一个

5. **保持原生**：仅做增强，不改动 dsh 原有界面与逻辑

6. **只携带「插件市场」**：不含任何第三方插件，其余插件由你自行安装

7. **更新dsh版本检测**：更新dsh新版本时，如有插件不兼容，会自动关闭插件，并隔离和提示

## 说明：

1.设置-通用设置增加Enter（回车）功能，设置为换行时，可在会话消息框处换行，避免按错发送，并自动改为Ctrl+Enter发送对话

2.设置-通用设置增加关闭按钮的功能，可设置最小化与直接关闭程序

3.设置-通用设置增加标题栏颜色，可设置跟随软件、跟随系统、自定义（取色盘）

4.设置-通用设置增加在系统盘常驻与开机自启动

5.设置-通用设置增加合并记录，合并记录说明见下方

6.设置-通用设置增加回滚快照功能，可自定义时间，自动备份文件（最多 3 份滚动）

7.设置-通用设置增加检查更新，可检测dsh内核版本，并更新

8.第三方中转的curl等部署代码可通过「通过代码添加」实现复制粘贴自动识别

9.设置-通用设置增加「无限报错重试」，报错后由 dsh 后台自动重试

10.「不兼容插件」警示：标题栏 ⚠ 图标常显，检测到不兼容插件会变黄，点击可查看并一键跳到插件市场

11.崩溃自动介入：服务连续崩溃 3 次会自动从最近快照恢复内核


## 合并记录说明：

合并记录在第一次解压运行会提醒，设置里也可找到合并记录并更新

合并记录包括会话存档、插件、设置、API。原因在于客户端崩溃，用新客户端时可以快速部署

合并记录如果有多个文件夹的方式，会列出所有的地址，可以自由选择合并哪个文件

合并记录的会话、插件、设置、API也可以随意选择

注意：如果某些情况下客户端出错，用新客户端合并时，谨慎合并会话记录。偶有发生记录不全的现象。

**注意**：程序数据（会话、插件、设置）就在解压目录的 `data\` 内。若要重装，请**先退出客户端**再直接运行新的 exe（会自动覆盖程序文件，数据保留）；**不要直接删除整个解压目录**，否则数据会一起丢失。
