# DSH Desktop（DeepSeek Harness 桌面端）

DeepSeek Harness 的 Windows 桌面客户端，**免安装，解压即用**。

## 版本

- 当前版本：**v0.3.7**
- 支持系统：Windows 10 / Windows 11

## 使用方法

1. 从右侧 **Releases（版本发布）** 页面下载附件：
   - `DSH-Desktop-v0.3.7-setup.exe` —— 自解压安装包，双击后自动解压
   - `DSH-Desktop-v0.3.7.zip` —— 压缩包，手动解压
2. 解压后进入文件夹，双击运行 **`DSH Desktop.exe`** 即可启动。

> 两种文件解压后的内容完全一样，任选其一下载即可。

## 说明

- 本仓库只发布打包好的客户端，不包含源码。
- 程序自带运行所需环境，无需安装 Node.js 等任何额外依赖。
